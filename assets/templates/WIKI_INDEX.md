# 项目知识索引

> 这是知识查询入口，不是新的需求、视觉或技术事实源。原始资料、编译知识和摄取日志分别位于 `raw_sources/`、`wiki/` 和 `logs/ingestion/`。

## 查询顺序

1. 先读取用户最新要求和唯一任务台账。
2. 按问题类型读取对应结构化事实源。
3. 只有结构化事实不足、冲突或需要核验来源时，才追溯原始资料、代码、测试或 Git 历史。
4. 外部事实可能变化时重新核验，不把旧摘要当成当前事实。

## 结构化知识地图

| 问题 | 先读 | 必要时追溯 |
| --- | --- | --- |
| 当前目标、阻塞、证据和下一步 | `TASK_LEDGER.md` 或已有 `PROJECT_STATUS.md` | 当前 diff、测试与提交 |
| 产品行为与验收 | `SPEC.md` | 用户最新明确决定 |
| 视觉、交互与参考范围 | `DESIGN.md` | 原稿、来源与真实界面 |
| 架构、数据、接口、安全与发布 | `TECHNICAL.md` | 当前代码、测试与官方文档 |
| 稳定项目结论 | `MEMORY.md` | 条目中的证据指针 |
| 可复用方法 | `EVOLUTION.md` | 对应真实案例、测试或提交 |
