# 项目长期记忆

> 只保存跨会话仍稳定、可复用且可追溯的项目结论。当前进度、待办和阻塞写入唯一任务台账。

## 记忆准入

一条内容只有同时满足以下条件才进入本文件：

1. 以后仍会影响判断或执行；
2. 能指向权威文档、代码、测试、提交或用户明确决定；
3. 不含凭证、敏感信息、临时猜测、会话流水或容易快速过期的外部事实。

结论变化时更新原条目或标记被替代，不追加相互矛盾的新版本。
