# 任务台账

> 这是唯一执行控制面，只保存当前工作包、依赖、状态、验收、证据、阻塞和恢复动作。产品、视觉与技术规则链接到对应权威文档；完成历史由 Git 保存。

## 使用规则

- 状态：`PENDING / READY / ACTIVE / VERIFY / BLOCKED / DONE / SUPERSEDED`。
- 同一时刻最多一个 `ACTIVE` 工作包，并保持唯一下一项。
- 开始、完成、阻塞、拆分或合并工作包时立即回写。
- 状态变化时替换过时事实，不追加会话历史。
- Agent 报告、文件存在、测试数量和旧日志不能单独证明完成。
