# 任务台账

> 唯一执行控制面。记录当前目标、任务拆分、状态、阻塞、下一步动作、验收标准和证据位置；产品、视觉与技术规则只链接到权威文档。

## 使用规则

- 状态：`PENDING / READY / ACTIVE / VERIFY / BLOCKED / DONE / SUPERSEDED`。
- 只保留一个当前 Goal；一个执行波次可有多个互不依赖、所有权互斥的 `ACTIVE` 工作包。
- 每个工作包必须有负责人、边界、依赖、验收、验证、证据和自己的下一步动作；高风险项再写回滚、禁止动作和人类确认点。
- 开始、完成、阻塞、拆分或合并工作包时替换旧事实，不追加会话流水。
- Agent 报告、文件存在、测试数量和旧日志不能单独证明完成。

## 当前可执行项：INIT-01

### 目标与边界

- 目标：确认项目目标、非目标、事实源、风险和首个可观察验收结果。
- 非目标：不在目标和边界未确认时铺开实现。

### 依赖、负责人和预计读写范围

- 依赖：用户最新要求与当前项目事实。
- 负责人：主 Agent。
- 预计读取：项目入口、现有实现与适用权威文档。
- 预计写入：本台账及真正发生事实变化的权威文档。

### 验收标准与验证方式

1. 目标、非目标和首个可观察结果明确。
2. 依赖、风险、暂停条件和本项下一步动作明确。
3. 当前文档和工作区没有未解决的事实冲突。

验证方式：审查当前 diff、事实源链接与工作区状态。
